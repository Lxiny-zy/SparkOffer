# Python 函数与作用域

## 函数定义与参数

### 参数类型

1. **位置参数（Positional）**：按顺序传递，最基本的参数类型
2. **默认参数（Default）**：有默认值，调用时可省略。**注意：默认值只在函数定义时计算一次**
3. **可变位置参数 `*args`**：接收任意数量位置参数，打包为元组
4. **关键字参数 `**kwargs`**：接收任意数量关键字参数，打包为字典
5. **仅限关键字参数（Keyword-only）**：`*` 后面的参数必须用关键字传递
6. **仅限位置参数（Positional-only）**：Python 3.8+，`/` 前面的参数只能按位置传递

```python
# 参数类型完整示例（Python 3.8+）
def func(pos_only, /, normal, *, kw_only, **kwargs):
    """
    pos_only: 仅限位置参数（/ 之前）
    normal: 普通参数
    kw_only: 仅限关键字参数（* 之后）
    **kwargs: 剩余关键字参数
    """
    pass

func(1, 2, kw_only=3)           # OK
func(1, normal=2, kw_only=3)    # OK
# func(pos_only=1, normal=2, kw_only=3)  # TypeError!

# 参数顺序规则
def complete(pos_only, /, normal, default=10, *args, kw_only, **kwargs):
    pass

# 默认参数陷阱：可变对象做默认值
def bad(lst=[]):     # 错误！每次调用共享同一个列表
    lst.append(1)
    return lst

print(bad())  # [1]
print(bad())  # [1, 1]  不是 [1]！
print(bad())  # [1, 1, 1]  持续累积

# 查看默认值：它是函数对象的属性
print(bad.__defaults__)  # ([1, 1, 1],)

def good(lst=None):  # 正确做法
    if lst is None:
        lst = []
    lst.append(1)
    return lst

# 更 Pythonic 的写法：用 sentinel 区分 None 和未传参
_MISSING = object()

def smart(value=_MISSING):
    if value is _MISSING:
        print("未传参")
    elif value is None:
        print("传了 None")
    else:
        print(f"传了 {value}")
```

### 参数传递机制

Python 是"传对象引用"（pass by object reference），也叫"传共享"（call by sharing）。

```python
# 不可变对象：函数内"修改"实际上是重新绑定，不影响外部
def try_modify_int(x):
    print(f"修改前 id: {id(x)}")
    x = x + 1  # x 被重新绑定到新的 int 对象
    print(f"修改后 id: {id(x)}")

a = 10
try_modify_int(a)
print(a)  # 10，不变

# 可变对象：函数内修改影响外部
def try_modify_list(lst):
    lst.append(4)     # 原地修改，影响外部
    lst = [100, 200]  # 重新绑定，不影响外部
    lst.append(300)

my_list = [1, 2, 3]
try_modify_list(my_list)
print(my_list)  # [1, 2, 3, 4]  只有 append 生效

# 如果需要在函数内修改不可变对象？返回新值
def increment(x):
    return x + 1

a = 10
a = increment(a)  # 重新绑定

# 防御性编程：不想修改传入的可变参数
def safe_process(data):
    data = data.copy()  # 先拷贝
    data.append(999)
    return data
```

## 作用域 LEGB 规则

Python 查找变量的顺序（从内到外）：
1. **L（Local）**：当前函数内部的局部变量
2. **E（Enclosing）**：外层嵌套函数的局部变量
3. **G（Global）**：模块级别的全局变量
4. **B（Built-in）**：Python 内置名称（如 `len`, `print`, `range`）

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)  # "local"  -- L
    inner()
    print(x)      # "enclosing"  -- E

outer()
print(x)          # "global"  -- G

# 注意：for 循环没有独立作用域！
for i in range(5):
    pass
print(i)  # 4，i 在循环外仍然可用（Python 没有块级作用域）

# 列表推导式有独立作用域（Python 3）
squares = [x**2 for x in range(5)]
# print(x)  # 如果外部没定义 x，这里会 NameError（Python 3）

# global 关键字：在函数内修改全局变量
count = 0

def increment():
    global count
    count += 1

increment()
print(count)  # 1

# nonlocal 关键字：在嵌套函数内修改外层变量
def outer():
    x = 10
    def inner():
        nonlocal x
        x = 20
    inner()
    print(x)  # 20

# 常见陷阱：UnboundLocalError
x = 10
def broken():
    # print(x)  # UnboundLocalError!
    # Python 在编译时发现函数内有对 x 的赋值，所以将 x 视为局部变量
    # 但 print 在赋值之前，此时 x 还未绑定
    x = 20     # 这一行导致 x 被视为局部变量

# 正确做法
def fixed():
    global x
    print(x)   # 10
    x = 20     # 修改全局 x
```

## 闭包

- 内部函数引用了外部函数的变量，且外部函数已经返回
- 闭包的本质：函数 + 引用环境
- 闭包可以保持状态，是装饰器的基础

```python
# 基本闭包
def make_counter():
    count = 0
    def counter():
        nonlocal count
        count += 1
        return count
    return counter

c = make_counter()
print(c())  # 1
print(c())  # 2

# 查看闭包变量
print(c.__closure__)          # 元组，每个元素是一个 cell 对象
print(c.__closure__[0].cell_contents)  # 2

# 闭包实现简单缓存
def memoize(func):
    cache = {}
    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]
    return wrapper

@memoize
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(100))  # 瞬间返回

# 经典闭包陷阱：循环中的闭包
def make_functions():
    functions = []
    for i in range(5):
        def f():
            return i   # 闭包引用的是变量 i，不是 i 的值
        functions.append(f)
    return functions

funcs = make_functions()
print([f() for f in funcs])  # [4, 4, 4, 4, 4]  全是 4！

# 修复方法1：默认参数（在定义时绑定值）
def make_functions_fixed():
    functions = []
    for i in range(5):
        def f(i=i):    # 默认参数在定义时求值
            return i
        functions.append(f)
    return functions

print([f() for f in make_functions_fixed()])  # [0, 1, 2, 3, 4]

# 修复方法2：使用 functools.partial
from functools import partial

def make_functions_fixed2():
    functions = []
    for i in range(5):
        functions.append(partial(lambda i: i, i))
    return functions

# 修复方法3：再包一层（立即调用）
def make_functions_fixed3():
    functions = []
    for i in range(5):
        def make(i):
            def f():
                return i
            return f
        functions.append(make(i))
    return functions

# 闭包实现状态机
def make_state_machine():
    state = 'idle'

    def transition(event):
        nonlocal state
        transitions = {
            ('idle', 'start'): 'running',
            ('running', 'pause'): 'paused',
            ('paused', 'resume'): 'running',
            ('running', 'stop'): 'idle',
            ('paused', 'stop'): 'idle',
        }
        new_state = transitions.get((state, event))
        if new_state:
            state = new_state
            return f"状态: {state}"
        return f"无效转换: {state} + {event}"

    return transition

sm = make_state_machine()
print(sm('start'))   # 状态: running
print(sm('pause'))   # 状态: paused
print(sm('resume'))  # 状态: running
```

## 装饰器

### 装饰器的本质

装饰器是一个接受函数并返回新函数的高阶函数。`@decorator` 是语法糖。

```python
# @decorator 等价于：
# func = decorator(func)

# 最简单的装饰器
def simple_decorator(func):
    def wrapper(*args, **kwargs):
        print("调用前")
        result = func(*args, **kwargs)
        print("调用后")
        return result
    return wrapper

@simple_decorator
def say_hello(name):
    """打招呼"""
    print(f"Hello, {name}")

# 等价于：say_hello = simple_decorator(say_hello)
say_hello("World")
# 输出: 调用前 / Hello, World / 调用后

# 问题：装饰后函数的元信息丢失
print(say_hello.__name__)    # wrapper（不是 say_hello）
print(say_hello.__doc__)     # None（不是 "打招呼"）
```

### functools.wraps 保留元信息

```python
import functools
import time

def timer(func):
    @functools.wraps(func)  # 保留原函数的 __name__, __doc__, __module__ 等
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        elapsed = time.time() - start
        print(f"{func.__name__} 耗时: {elapsed:.4f}s")
        return result
    return wrapper

@timer
def slow_func():
    """一个很慢的函数"""
    time.sleep(1)

print(slow_func.__name__)  # slow_func（正确）
print(slow_func.__doc__)   # 一个很慢的函数（正确）

# 还可以访问被装饰的原函数
print(slow_func.__wrapped__)  # 原始 slow_func
```

### 带参数的装饰器（三层嵌套）

```python
def repeat(n):
    """重复执行 n 次"""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            result = None
            for _ in range(n):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def greet(name):
    print(f"Hello, {name}")

# 等价于：greet = repeat(3)(greet)
greet("World")  # 打印三次

# 实战：重试装饰器
def retry(max_retries=3, exceptions=(Exception,), delay=1):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    if attempt == max_retries - 1:
                        raise
                    print(f"第{attempt+1}次失败: {e}，{delay}秒后重试...")
                    time.sleep(delay)
        return wrapper
    return decorator

@retry(max_retries=3, exceptions=(ConnectionError,), delay=2)
def fetch_data(url):
    # 可能会失败的网络请求
    pass
```

### 类装饰器

```python
# 用类实现装饰器
class Timer:
    def __init__(self, func):
        functools.update_wrapper(self, func)
        self.func = func
        self.call_count = 0

    def __call__(self, *args, **kwargs):
        self.call_count += 1
        start = time.time()
        result = self.func(*args, **kwargs)
        print(f"[{self.call_count}] {self.func.__name__} 耗时: {time.time()-start:.4f}s")
        return result

@Timer
def compute(n):
    return sum(range(n))

compute(1000000)
compute(1000000)
print(compute.call_count)  # 2

# 装饰类的装饰器（给类增加功能）
def singleton(cls):
    """单例装饰器"""
    instances = {}
    @functools.wraps(cls)
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton
class Database:
    def __init__(self, host):
        self.host = host

db1 = Database("localhost")
db2 = Database("remote")  # 返回同一实例
print(db1 is db2)  # True
```

### 装饰器执行顺序

```python
def decorator_a(func):
    print("装饰器A 应用")
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("装饰器A 执行前")
        result = func(*args, **kwargs)
        print("装饰器A 执行后")
        return result
    return wrapper

def decorator_b(func):
    print("装饰器B 应用")
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("装饰器B 执行前")
        result = func(*args, **kwargs)
        print("装饰器B 执行后")
        return result
    return wrapper

@decorator_a
@decorator_b
def hello():
    print("Hello!")

# 应用（定义时）顺序：从下到上 B -> A
# 输出: 装饰器B 应用 / 装饰器A 应用

# 执行顺序：从上到下 A -> B
hello()
# 输出:
# 装饰器A 执行前
# 装饰器B 执行前
# Hello!
# 装饰器B 执行后
# 装饰器A 执行后

# 类比洋葱模型：A 是外层，B 是内层
```

### 实战：常用装饰器

```python
# 1. 缓存装饰器（LRU）
from functools import lru_cache

@lru_cache(maxsize=128)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(100))
print(fibonacci.cache_info())  # CacheInfo(hits=98, misses=101, ...)
fibonacci.cache_clear()

# 2. 参数类型检查装饰器
def type_check(**expected_types):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            import inspect
            sig = inspect.signature(func)
            bound = sig.bind(*args, **kwargs)
            for param_name, value in bound.arguments.items():
                if param_name in expected_types:
                    if not isinstance(value, expected_types[param_name]):
                        raise TypeError(
                            f"{param_name} 应为 {expected_types[param_name].__name__}，"
                            f"实际为 {type(value).__name__}"
                        )
            return func(*args, **kwargs)
        return wrapper
    return decorator

@type_check(name=str, age=int)
def create_user(name, age):
    return {"name": name, "age": age}

create_user("张三", 25)     # OK
# create_user("张三", "25")  # TypeError!

# 3. 权限检查装饰器
def require_role(role):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(user, *args, **kwargs):
            if role not in user.get('roles', []):
                raise PermissionError(f"需要 {role} 权限")
            return func(user, *args, **kwargs)
        return wrapper
    return decorator

@require_role("admin")
def delete_user(user, user_id):
    print(f"删除用户 {user_id}")

admin = {"name": "admin", "roles": ["admin", "user"]}
delete_user(admin, 123)  # OK

# 4. 日志装饰器
import logging

def log_call(logger=None, level=logging.INFO):
    def decorator(func):
        nonlocal logger
        if logger is None:
            logger = logging.getLogger(func.__module__)

        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            logger.log(level, f"调用 {func.__name__}(args={args}, kwargs={kwargs})")
            try:
                result = func(*args, **kwargs)
                logger.log(level, f"{func.__name__} 返回 {result}")
                return result
            except Exception as e:
                logger.exception(f"{func.__name__} 异常: {e}")
                raise
        return wrapper
    return decorator
```

```python
square = lambda x: x ** 2
```

## 高阶函数

```python
from functools import reduce

# map：对每个元素应用函数
nums = [1, 2, 3, 4, 5]
squares = list(map(lambda x: x**2, nums))    # [1, 4, 9, 16, 25]
# 等价于列表推导式：[x**2 for x in nums]

# filter：过滤元素
evens = list(filter(lambda x: x % 2 == 0, nums))  # [2, 4]
# 等价于：[x for x in nums if x % 2 == 0]

# reduce：累积计算
product = reduce(lambda x, y: x * y, nums)  # 120（1*2*3*4*5）

# sorted：排序（返回新列表）
words = ['banana', 'apple', 'cherry', 'date']
sorted_words = sorted(words, key=len)  # 按长度排序
sorted_words = sorted(words, key=str.lower)  # 不区分大小写

# functools.partial：偏函数，固定部分参数
from functools import partial

int_base2 = partial(int, base=2)
print(int_base2('1010'))  # 10

# 多函数组合
def compose(*funcs):
    """函数组合：compose(f, g, h)(x) == f(g(h(x)))"""
    def composed(x):
        for f in reversed(funcs):
            x = f(x)
        return x
    return composed

double = lambda x: x * 2
increment = lambda x: x + 1
double_then_inc = compose(increment, double)  # 先 double 后 increment
print(double_then_inc(3))  # 7

# any / all：高阶布尔函数
nums = [1, 2, 3, 4, 5]
print(any(x > 4 for x in nums))  # True
print(all(x > 0 for x in nums))  # True
```

## 递归

```python
# 基本递归
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

# Python 默认递归深度限制 1000
import sys
print(sys.getrecursionlimit())  # 1000
sys.setrecursionlimit(10000)    # 可以修改，但不推荐设太大

# 尾递归优化：Python 不支持尾递归优化（Guido 有意不加）
# 解决方案：改用迭代，或用 lru_cache 做记忆化

# 记忆化递归
@lru_cache(maxsize=None)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# 改为迭代（更好）
def fibonacci_iter(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## 踩坑指南

### 坑1：延迟绑定问题
```python
# 闭包和 lambda 都是延迟绑定
fns = [lambda: i for i in range(5)]
print([f() for f in fns])  # [4, 4, 4, 4, 4]

# 修复：默认参数
fns = [lambda i=i: i for i in range(5)]
print([f() for f in fns])  # [0, 1, 2, 3, 4]
```

### 坑2：装饰器丢失元信息
```python
# 不用 @functools.wraps 会导致：
# - __name__ 变成 wrapper
# - __doc__ 变成 None
# - inspect.signature 不正确
# - pickle 无法序列化
# 解决：始终使用 @functools.wraps(func)
```

### 坑3：可变默认参数
```python
# 时间戳默认参数也是陷阱
from datetime import datetime

def log(message, timestamp=datetime.now()):  # 只在定义时算一次！
    print(f"[{timestamp}] {message}")

# 每次调用 timestamp 都是同一个时间
# 正确做法
def log(message, timestamp=None):
    if timestamp is None:
        timestamp = datetime.now()
    print(f"[{timestamp}] {message}")
```

### 坑4：递归深度限制

## 最佳实践

1. **函数保持短小**：一个函数做一件事，不超过 20-30 行
2. **有意义的命名**：函数名用动词开头（`get_user`, `calculate_total`）
3. **避免副作用**：尽量写纯函数（相同输入总是相同输出）
4. **装饰器必加 @functools.wraps**：保留元信息
5. **不用可变对象做默认参数**：用 None 代替
6. **优先用列表推导式而非 map/filter**：更 Pythonic，可读性更好
7. **少用 global**：用参数和返回值传递数据，global 破坏模块化
8. **递归加缓存或改迭代**：避免重复计算和栈溢出
9. **合理使用类型注解**：提升可读性和 IDE 支持
10. **lambda 只用于简单场景**：复杂逻辑用 def 定义具名函数

## 面试高频问题

### Q1: 装饰器的原理和应用场景？
**答**：装饰器本质是一个高阶函数，接受函数作为参数并返回新函数。`@decorator` 是 `func = decorator(func)` 的语法糖。应用场景包括：日志记录、性能计时、权限检查、缓存（如 `@lru_cache`）、重试机制、事务管理、路由注册（Flask/Django）。带参数的装饰器需要三层嵌套。必须使用 `@functools.wraps` 保留原函数的元信息。

### Q2: 闭包是什么？有什么用？
**答**：闭包是指内部函数引用了外部函数的变量，且外部函数已经返回。闭包 = 函数 + 引用环境。闭包能保持状态而不使用全局变量，是装饰器的基础。可以通过 `func.__closure__` 访问闭包变量。注意循环中的闭包陷阱（延迟绑定），需要用默认参数绑定当前值。

### Q3: Python 函数参数是传值还是传引用？
**答**：都不完全准确，Python 使用"传对象引用"（call by object reference / call by sharing）。函数参数接收的是对象的引用（指针），但不是 C++ 的引用。对于不可变对象（int, str, tuple），函数内"修改"实际是重新绑定到新对象，不影响外部；对于可变对象（list, dict），原地修改会影响外部，但重新赋值不会。

### Q4: 为什么不能用可变对象做函数默认参数？
**答**：因为默认参数值在函数**定义时**只计算一次，存储在 `func.__defaults__` 中。每次调用共享同一个默认对象。如果是可变对象（如列表），修改会累积。正确做法是用 `None` 作默认值，在函数体内创建新对象。

### Q5: LEGB 规则是什么？
**答**：LEGB 是 Python 变量查找顺序：Local（当前函数） -> Enclosing（外层嵌套函数） -> Global（模块全局） -> Built-in（Python 内置）。`global` 关键字声明使用全局变量，`nonlocal` 声明使用外层函数变量。注意 Python 没有块级作用域，for 循环变量在循环外仍可用。

### Q6: 装饰器的执行顺序？多个装饰器如何叠加？
**答**：多个装饰器从下到上应用（定义时），从上到下执行（调用时）。类比洋葱模型：最外层装饰器最先/最后执行。`@A @B def f` 等价于 `f = A(B(f))`，调用时先进入 A 的 wrapper，再进入 B 的 wrapper，再执行 f，然后按逆序返回。

### Q7: lru_cache 的原理和使用场景？
**答**：`@lru_cache` 是标准库提供的最近最少使用缓存装饰器。底层使用字典存储结果，双向链表维护使用顺序。参数会被转为 hashable 的 key。适用于纯函数（相同输入相同输出）的结果缓存，如递归计算、数据库查询结果缓存。`maxsize=None` 表示不限大小。使用 `cache_info()` 查看命中率，`cache_clear()` 清除缓存。注意参数必须可哈希。

### Q8: 如何实现一个既可以带参数又可以不带参数的装饰器？
**答**：
```python
def smart_decorator(func=None, *, retries=3, delay=1):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for i in range(retries):
                try:
                    return func(*args, **kwargs)
                except Exception:
                    if i == retries - 1:
                        raise
                    time.sleep(delay)
        return wrapper

    if func is not None:
        return decorator(func)  # 不带参数：@smart_decorator
    return decorator              # 带参数：@smart_decorator(retries=5)

@smart_decorator           # 不带参数
def func1(): pass

@smart_decorator(retries=5)  # 带参数
def func2(): pass
```

### Q9: Python 中函数是一等公民是什么意思？
**答**：函数是一等对象（first-class object），和 int、str 一样是对象。可以：(1) 赋值给变量；(2) 作为参数传递；(3) 作为返回值；(4) 存储在数据结构中；(5) 拥有属性（`__name__`, `__doc__` 等）。这使得高阶函数、闭包、装饰器等模式成为可能。

### Q10: partial 偏函数和闭包有什么区别？
**答**：`functools.partial` 是冻结部分参数生成新函数，底层实现不是闭包而是 `partial` 对象。与闭包的区别：partial 更明确，只能固定参数；闭包更灵活，可以封装任意逻辑和状态。partial 保留了原函数签名信息，方便 introspection。使用场景：固定某些参数创建特化版本（如 `int_base2 = partial(int, base=2)`）。
