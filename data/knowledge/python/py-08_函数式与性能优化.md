# Python 函数式编程与性能优化

## 一、函数式编程

### 1. 头等函数（First-class Function）
函数是对象，可赋值、传参、返回。

```python
def add(a, b): return a + b

# 赋值
f = add
print(f(1, 2))  # 3

# 传参
def apply(func, a, b): return func(a, b)
apply(add, 1, 2)

# 返回
def multiplier(n):
    def inner(x): return x * n
    return inner
double = multiplier(2)
double(5)  # 10
```

### 2. Lambda

```python
square = lambda x: x ** 2
sorted(['banana', 'apple'], key=lambda s: len(s))
```

**限制**：只能单表达式、无文档字符串。复杂逻辑用 def。

### 3. 高阶函数

**map**：
```python
list(map(lambda x: x * 2, [1, 2, 3]))  # [2, 4, 6]
```

**filter**：
```python
list(filter(lambda x: x > 0, [-1, 0, 1, 2]))  # [1, 2]
```

**reduce**：
```python
from functools import reduce
reduce(lambda a, b: a + b, [1, 2, 3, 4])  # 10
reduce(lambda a, b: a + b, [1, 2, 3, 4], 100)  # 带初始值
```

**推导式优于 map/filter**（更 Pythonic）：
```python
[x * 2 for x in nums]
[x for x in nums if x > 0]
```

### 4. functools 模块

```python
from functools import reduce, partial, lru_cache, wraps, singledispatch, cache
```

**partial（偏函数）**：
```python
from functools import partial
def power(base, exp): return base ** exp
square = partial(power, exp=2)
square(5)  # 25
```

**lru_cache（缓存）**：
```python
@lru_cache(maxsize=128)
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)

fib(100)  # 快，因缓存
fib.cache_info()  # 查看命中率
```

Python 3.9+ `@cache`（无大小限制）。

**wraps（装饰器保留元信息）**：
```python
from functools import wraps

def log(func):
    @wraps(func)  # 保留 func.__name__ 等
    def wrapper(*args, **kwargs):
        print(f"call {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

**singledispatch（函数重载）**：
```python
from functools import singledispatch

@singledispatch
def process(arg):
    raise NotImplementedError()

@process.register(int)
def _(arg): return arg * 2

@process.register(str)
def _(arg): return arg.upper()

process(5)      # 10
process("hi")   # "HI"
```

### 5. itertools 模块

**无限迭代器**：
```python
from itertools import count, cycle, repeat
count(10, 2)   # 10, 12, 14, ...
cycle('AB')    # A, B, A, B, ...
repeat(5, 3)   # 5, 5, 5
```

**组合**：
```python
from itertools import chain, product, permutations, combinations

chain([1,2], [3,4])                  # 1 2 3 4
list(product('AB', repeat=2))        # AA AB BA BB
list(permutations('ABC', 2))         # AB AC BA BC CA CB
list(combinations('ABC', 2))         # AB AC BC
```

**分组**：
```python
from itertools import groupby
sorted_data = sorted(data, key=lambda x: x.type)
for key, group in groupby(sorted_data, key=lambda x: x.type):
    print(key, list(group))
```

**切片**：
```python
from itertools import islice
list(islice(iterable, 10))  # 取前 10 个（不耗空间）
```

### 6. 纯函数与不可变

**纯函数**：
- 相同输入 → 相同输出
- 无副作用

```python
# 纯
def add(a, b): return a + b

# 不纯
total = 0
def add_to_total(x):
    global total
    total += x
```

**不可变数据**：
```python
from dataclasses import dataclass, replace

@dataclass(frozen=True)
class Point:
    x: int
    y: int

p1 = Point(1, 2)
p2 = replace(p1, x=10)  # 创建新实例
```

### 7. 柯里化

```python
from functools import partial

def add3(a, b, c): return a + b + c

# 柯里化
add3_curry = lambda a: lambda b: lambda c: a + b + c
add3_curry(1)(2)(3)  # 6

# 或用 partial
partial(partial(add3, 1), 2)(3)  # 6
```

### 8. 生成器（函数式思维）

```python
def even_nums(limit):
    for i in range(limit):
        if i % 2 == 0:
            yield i

for n in even_nums(10):
    print(n)
```

**惰性求值**，节省内存。

## 二、性能优化

### 1. 基础原则

1. **先测量再优化**：用 `cProfile` / `line_profiler` 找瓶颈
2. **算法优先**：O(n²) → O(n log n) 远比微优化有效
3. **80/20 原则**：80% 时间在 20% 代码
4. **不过度优化**：可读性优先

### 2. 性能分析

**cProfile**：
```python
import cProfile
cProfile.run('my_function()')
# 或
python -m cProfile -s cumtime myscript.py
```

**line_profiler**（需装）：
```bash
pip install line_profiler
```
```python
@profile  # kernprof 命令行运行
def slow_function():
    ...
```

**memory_profiler**：
```python
@profile
def func(): ...
```

**timeit**：
```python
import timeit
timeit.timeit('[x*2 for x in range(100)]', number=10000)
```

### 3. 数据结构选择

| 操作 | list | deque | set | dict |
|------|------|-------|-----|------|
| 尾部 append | O(1) | O(1) | - | - |
| 头部 insert | O(n) | O(1) | - | - |
| 查找 in | O(n) | O(n) | O(1) | O(1) |
| 随机访问 | O(1) | O(n) | - | O(1) by key |

**去重 + 查找**用 set：
```python
# 慢
common = [x for x in a if x in b]  # O(n*m)

# 快
b_set = set(b)
common = [x for x in a if x in b_set]  # O(n+m)
```

### 4. 内置 > 手写

```python
# 慢
total = 0
for x in nums: total += x

# 快
total = sum(nums)

# map 比手写 for 快（C 实现）
result = list(map(str, nums))
```

### 5. 推导式 vs 循环

```python
# 推导式（C 优化，快）
result = [x * 2 for x in nums if x > 0]

# 显式循环（稍慢）
result = []
for x in nums:
    if x > 0:
        result.append(x * 2)
```

### 6. 局部变量 > 全局

```python
import math

# 慢
def calc(nums):
    return [math.sqrt(x) for x in nums]

# 快：局部化
def calc(nums):
    sqrt = math.sqrt
    return [sqrt(x) for x in nums]
```

局部变量访问 (LOAD_FAST) 比全局 (LOAD_GLOBAL) 快。

### 7. 字符串拼接

```python
# 慢（反复创建新字符串）
s = ""
for x in strings:
    s += x

# 快
s = "".join(strings)
```

### 8. 避免属性查找

```python
# 循环中反复查 obj.method
for _ in range(1000000):
    obj.do_something()

# 优化
method = obj.do_something
for _ in range(1000000):
    method()
```

### 9. 懒加载与生成器

```python
# 一次性生成大 list（内存爆）
lines = [process(line) for line in open("big.txt")]

# 生成器（流式）
lines = (process(line) for line in open("big.txt"))
for l in lines:
    handle(l)
```

### 10. 并发加速

**I/O 密集**：
- `asyncio` 协程
- `concurrent.futures.ThreadPoolExecutor`

**CPU 密集**：
- `multiprocessing`
- `concurrent.futures.ProcessPoolExecutor`
- NumPy 向量化
- Cython / C 扩展

```python
from concurrent.futures import ProcessPoolExecutor
with ProcessPoolExecutor() as pool:
    results = list(pool.map(heavy_compute, data))
```

### 11. NumPy 向量化

```python
import numpy as np

# 慢（Python 循环）
result = [x * 2 for x in nums]

# 快（NumPy）
arr = np.array(nums)
result = arr * 2
```

向量化比 Python 循环快 10-100 倍。

### 12. Cython / Numba

**Numba（JIT）**：
```python
from numba import jit

@jit(nopython=True)
def compute(n):
    total = 0
    for i in range(n):
        total += i
    return total
```

**Cython**：C 扩展，需要编译。适合热点函数。

### 13. 缓存

**lru_cache**（见上）

**全局缓存**：
```python
import redis
r = redis.Redis()
def get_user(user_id):
    cached = r.get(f"user:{user_id}")
    if cached: return json.loads(cached)
    user = db.query(...)
    r.setex(f"user:{user_id}", 3600, json.dumps(user))
    return user
```

### 14. 字节码优化（Python 3.11+）
Python 3.11 性能比 3.10 提升 10-60%。**升级 Python 版本** 是免费优化。

Python 3.13 实验性 no-GIL 模式（PEP 703）。

### 15. __slots__

```python
class Point:
    __slots__ = ('x', 'y')  # 不能动态加字段
    def __init__(self, x, y):
        self.x = x; self.y = y
```

- 省内存（无 `__dict__`）
- 属性访问稍快
- **限制**：不能动态加属性

### 16. 字符串 intern

```python
import sys
s1 = sys.intern("hello")
s2 = sys.intern("hello")
s1 is s2  # True

# 小字符串、字面量自动 intern
```

大量重复字符串（key、标签）可 intern 省内存。

### 17. 减少函数调用开销

```python
# 避免小函数
def inc(x): return x + 1
result = sum(inc(x) for x in nums)

# 直接
result = sum(x + 1 for x in nums)
```

Python 函数调用开销相对大。

### 18. 避免不必要的类型转换

```python
# 慢
for s in strs:
    if int(s) > threshold: ...

# 快
threshold_str = str(threshold)
for s in strs:
    if s > threshold_str: ...  # 字符串比较
```

（仅当场景合适）

### 19. PyPy（JIT Python）

```bash
pip install pypy3
pypy3 my_script.py
```
PyPy 对纯 Python 代码可加速 3-10 倍。但：
- 不完全兼容 CPython 扩展
- NumPy 等 C 扩展速度反而慢

### 20. 避免 Python 层面的并行陷阱

GIL 限制：
- **多线程对 CPU 密集无加速**
- IO 密集才用多线程
- CPU 密集用多进程或 C 扩展

## 三、实战优化案例

### 案例 1：大文件统计

```python
# 慢：一次读入
with open("huge.log") as f:
    lines = f.readlines()
    count = sum(1 for l in lines if "ERROR" in l)

# 快：逐行
with open("huge.log") as f:
    count = sum(1 for l in f if "ERROR" in l)
```

### 案例 2：频繁查找

```python
# 慢：O(n) 查找
def find_user(id, users):
    for u in users:
        if u.id == id: return u

# 快：预建索引
user_map = {u.id: u for u in users}
def find_user(id): return user_map.get(id)
```

### 案例 3：数值计算

```python
# 慢：Python 循环
def euclidean(a, b):
    return (sum((x - y) ** 2 for x, y in zip(a, b))) ** 0.5

# 快：NumPy
def euclidean(a, b):
    return np.linalg.norm(np.array(a) - np.array(b))
```

### 案例 4：API 并发调用

```python
# 串行慢
results = [fetch(url) for url in urls]

# 并发
from concurrent.futures import ThreadPoolExecutor
with ThreadPoolExecutor(max_workers=10) as pool:
    results = list(pool.map(fetch, urls))

# asyncio（最快）
import aiohttp, asyncio
async def fetch_all(urls):
    async with aiohttp.ClientSession() as session:
        return await asyncio.gather(*(fetch(session, u) for u in urls))
```

## 四、异步 asyncio 深入

### 事件循环
```python
import asyncio

async def hello():
    print("start")
    await asyncio.sleep(1)
    print("end")

asyncio.run(hello())
```

### gather 并发
```python
async def main():
    results = await asyncio.gather(
        fetch("a"), fetch("b"), fetch("c")
    )
```

### TaskGroup（Python 3.11+）
```python
async def main():
    async with asyncio.TaskGroup() as tg:
        t1 = tg.create_task(fetch("a"))
        t2 = tg.create_task(fetch("b"))
    # 所有任务完成
```

### 超时
```python
try:
    await asyncio.wait_for(fetch(url), timeout=5)
except asyncio.TimeoutError:
    ...
```

### 混合同步与异步
```python
# 在 async 里跑阻塞代码
await asyncio.to_thread(blocking_func, arg)
# 或
loop = asyncio.get_running_loop()
await loop.run_in_executor(None, blocking_func, arg)
```

## 面试高频问题

**Q1：Python 函数式特性有哪些？**

- 头等函数（可传参、返回、赋值）
- Lambda
- map/filter/reduce
- functools（partial、lru_cache、wraps、singledispatch）
- itertools
- 推导式（更 Pythonic）
- 生成器（惰性）

Python 不是纯函数式语言，但吸收了很多函数式特性。

**Q2：装饰器原理？**

本质是**高阶函数**：接收函数返回新函数。

```python
def log(func):
    def wrapper(*args, **kwargs):
        print("before")
        return func(*args, **kwargs)
    return wrapper

@log
def hello(): print("hi")

# 等价于 hello = log(hello)
```

关键点：
- 用 `@functools.wraps` 保留原函数元信息
- 可接受参数（装饰器工厂）
- 类也可做装饰器

**Q3：lru_cache 原理？**

字典 + 双向链表实现 LRU。相同参数返回缓存。

```python
@lru_cache(maxsize=128)
def slow(x): ...
```

注意：
- 参数必须 hashable
- `maxsize=None` 无限制（Python 3.9+ 用 `@cache`）
- `cache_info()` / `cache_clear()` 可查看/清空
- 类方法用 `@lru_cache` 会内存泄漏（self 被引用），用 `@functools.cached_property` 或 weakref

**Q4：Python 性能慢的原因？**

- 解释执行（无 JIT，CPython）
- GIL 限制多核
- 动态类型（运行时查找）
- 对象开销大（PyObject 头）
- 函数调用开销大

**优化**：
- 算法优先
- C 扩展（NumPy）
- JIT（Numba、PyPy）
- 并发（多进程、asyncio）
- 升级 Python（3.11+ 有显著加速）

**Q5：list 推导式 vs for 循环？**

推导式更快（C 优化 + 跳过 append 查找）：
```python
# 推导式 ≈ 比显式循环快 30-50%
[x*2 for x in nums]
```

**但**：
- 复杂逻辑用显式循环更清晰
- 嵌套推导式可读性差
- 有副作用的不要用推导式

**Q6：多线程和多进程怎么选？**

- **IO 密集**（文件/网络/DB）：多线程，GIL 在 IO 时释放
- **CPU 密集**：多进程，绕过 GIL
- **都可用**：asyncio 协程（IO 密集更优）

**Q7：asyncio 的核心？**

- **事件循环**：调度协程
- **async def**：定义协程函数
- **await**：暂停等待（IO）
- **Task**：协程调度单元

```python
async def main():
    # 并发
    results = await asyncio.gather(task1(), task2())
```

**不能混用**：在 async 里调阻塞函数会卡死事件循环。用 `asyncio.to_thread` 切到线程。

**Q8：生成器 vs 列表性能？**

- **列表**：一次性生成，占内存
- **生成器**：按需生成，惰性

```python
# 占 1GB 内存
result = [x ** 2 for x in range(10**8)]

# 几乎不占内存
result = (x ** 2 for x in range(10**8))
```

遍历一次的场景用生成器，多次用列表。

**Q9：如何定位性能瓶颈？**

三级定位：
1. **宏观**：`time` / `timeit` 测总耗时
2. **函数级**：`cProfile` 看各函数耗时
3. **行级**：`line_profiler` 精确到行

内存：`memory_profiler` / `tracemalloc`

生产：APM（Sentry / Datadog / Arms）。

**Q10：`__slots__` 作用？**

限制类的属性集合，**不创建 `__dict__`**。

好处：
- 省内存（10-50%）
- 属性访问稍快
- 防止typo乱加属性

限制：
- 不能动态加属性
- 多继承复杂
- 不能用 `__dict__` 操作

适合：大量实例的简单数据类（如 Point）。dataclass 可加 `slots=True`（Python 3.10+）。
