# Python 模块、包与虚拟环境

## 模块与包

### 模块

- 一个 `.py` 文件就是一个模块
- 模块是 Python 代码组织的基本单元
- 模块本身也是一个对象，有自己的命名空间

```python
# 导入方式
import os                      # 导入整个模块
import os.path                  # 导入子模块
from os import path             # 从模块导入特定名称
from os.path import join, exists  # 导入多个
from os import *                # 导入所有（不推荐，污染命名空间）
import numpy as np              # 起别名

# __name__ 属性
# 模块被直接运行时：__name__ == "__main__"
# 模块被导入时：__name__ == 模块名

if __name__ == "__main__":
    # 只在直接运行时执行，被导入时不执行
    main()

# 模块的属性
print(__name__)      # 模块名
print(__file__)      # 模块文件路径
print(__doc__)       # 模块文档字符串
print(__package__)   # 所属包名
print(__spec__)      # 模块规格（importlib 相关）
print(dir())         # 模块中定义的所有名称
```

### 包

```python
# 包是包含 __init__.py 的目录
# 项目结构示例：
# mypackage/
#     __init__.py          # 包初始化文件
#     module_a.py
#     module_b.py
#     subpackage/
#         __init__.py
#         module_c.py

# __init__.py 的作用
# 1. 标识目录为包（Python 3.3+ 不强制要求，但推荐保留）
# 2. 定义包级别的变量和导入
# 3. 控制 from package import * 的行为

# mypackage/__init__.py 示例
"""mypackage 包"""

__version__ = "1.0.0"
__all__ = ["module_a", "module_b"]  # 控制 import *

# 便捷导入：让用户可以直接 from mypackage import ClassA
from .module_a import ClassA
from .module_b import func_b

# 相对导入 vs 绝对导入
# 绝对导入（推荐）
from mypackage.module_a import ClassA
from mypackage.subpackage.module_c import func_c

# 相对导入（只能在包内使用）
from . import module_b           # 当前包
from .module_a import ClassA     # 当前包的模块
from .. import other_module      # 上级包
from ..sibling import func       # 兄弟包

# __all__ 列表
# 在 module_a.py 中：
__all__ = ["ClassA", "func_a"]

# 效果：from module_a import * 只导入 ClassA 和 func_a
# 没有 __all__ 时，import * 导入所有不以 _ 开头的名称
```

### 导入机制详解

```python
import sys

# Python 模块搜索顺序：
# 1. sys.modules 缓存（已加载过的模块）
# 2. 内置模块（如 sys, os）
# 3. sys.path 中的路径：
#    - 脚本所在目录（或当前目录）
#    - PYTHONPATH 环境变量
#    - 安装路径（site-packages）

print(sys.path)  # 查看搜索路径
sys.path.insert(0, "/my/custom/path")  # 动态添加搜索路径

# 模块缓存：sys.modules
# 模块只会被加载一次，后续 import 直接从缓存获取
print('os' in sys.modules)  # True（如果已导入过）

# 强制重新加载模块
import importlib
import my_module
importlib.reload(my_module)  # 重新执行模块代码

# 模块的加载过程：
# 1. 创建模块对象
# 2. 将模块加入 sys.modules 缓存
# 3. 执行模块代码（从上到下）
# 注意：步骤2在步骤3之前，这是解决循环导入的关键

# 延迟导入（解决循环导入）
def get_config():
    from mypackage import config  # 在需要时才导入
    return config.settings

# 条件导入
try:
    import ujson as json  # 优先用更快的 ujson
except ImportError:
    import json           # 退而求其次用标准库

# 导入钩子（高级）
# sys.meta_path 和 sys.path_hooks 可以自定义导入行为
```

### 循环导入问题

```python
# 循环导入：A 导入 B，B 又导入 A

# module_a.py
# from module_b import func_b  # 在顶层导入 B
# def func_a():
#     return func_b() + 1

# module_b.py
# from module_a import func_a  # 在顶层导入 A -> 循环！
# def func_b():
#     return func_a() + 1

# 解决方案：

# 1. 延迟导入（推荐）
# module_a.py
def func_a():
    from module_b import func_b  # 在函数内导入
    return func_b() + 1

# 2. 重构（最佳）
# 提取公共部分到第三个模块，避免循环依赖

# 3. 导入整个模块而非具体名称
# module_a.py
import module_b
def func_a():
    return module_b.func_b() + 1

# 4. 将导入放到 TYPE_CHECKING 块中（仅用于类型注解）
from __future__ import annotations
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from module_b import ClassB  # 只在类型检查时导入

def func(b: "ClassB") -> None:  # 字符串注解（前向引用）
    pass
```

### 命名空间包（Namespace Package）

```python
# Python 3.3+ 支持命名空间包：没有 __init__.py 的包
# 允许同一个包分散在不同目录中

# 目录结构：
# path1/mypackage/module_a.py
# path2/mypackage/module_b.py

# 两个路径都在 sys.path 中时：

```

## 虚拟环境

### 为什么需要虚拟环境

- 不同项目依赖不同版本的库（项目A需要 Django 3.x，项目B需要 Django 4.x）
- 避免全局安装导致的版本冲突
- 保持系统 Python 环境干净
- 确保项目的可复现性（依赖锁定）
- 团队协作时统一环境

### 工具对比

| 工具 | 特点 | 适用场景 |
|------|------|---------|
| **venv** | Python 自带，轻量，无需安装 | 简单项目，入门 |
| **virtualenv** | 第三方，比 venv 更快，功能更丰富 | 需要支持旧 Python 版本 |
| **conda** | Anaconda 自带，支持非 Python 包 | 数据科学，需要 C 库 |
| **poetry** | 现代包管理，依赖解析优秀，lock 文件 | 库开发，正式项目 |
| **pipenv** | 自动管理虚拟环境，Pipfile | 应用开发 |
| **uv** | Rust 编写，极快，兼容 pip | 追求速度，新项目 |
| **pdm** | PEP 582 支持，现代标准 | 遵循最新 Python 标准 |
| **hatch** | 项目管理 + 环境管理 | 包发布 |

### venv 详解

```bash
# 创建虚拟环境
python -m venv .venv                    # 在当前目录创建 .venv
python -m venv --without-pip .venv      # 不安装 pip

python -m venv --system-site-packages .venv  # 可以访问系统级包

# 激活虚拟环境
source .venv/bin/activate       # Linux/Mac bash
source .venv/bin/activate.fish  # Fish shell
.venv\Scripts\activate          # Windows cmd
.venv\Scripts\Activate.ps1      # Windows PowerShell

# 查看当前环境
which python                    # 确认使用虚拟环境的 Python
python -c "import sys; print(sys.prefix)"

# 安装依赖
pip install requests
pip install requests==2.28.0    # 指定版本
pip install "requests>=2.28,<3.0"  # 版本范围
pip install -r requirements.txt  # 从文件安装

# 导出依赖
pip freeze > requirements.txt    # 导出所有包及版本
pip list                         # 列出已安装的包
pip show requests                # 查看包详情

# 退出虚拟环境
deactivate

# 删除虚拟环境
rm -rf .venv
```

### json

```python
import json

# 序列化（Python -> JSON）
data = {"name": "张三", "age": 25, "scores": [90, 85, 95]}

json_str = json.dumps(data, ensure_ascii=False, indent=2)
# ensure_ascii=False：允许中文
# indent=2：美化输出

with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 反序列化（JSON -> Python）
obj = json.loads(json_str)
with open("data.json", "r", encoding="utf-8") as f:
    obj = json.load(f)

# 自定义序列化
from datetime import datetime

class CustomEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, datetime):
            return obj.isoformat()
        if isinstance(obj, set):
            return list(obj)
        return super().default(obj)

json.dumps({"time": datetime.now()}, cls=CustomEncoder)

# 自定义反序列化
def custom_decoder(dct):
    if 'time' in dct:
        dct['time'] = datetime.fromisoformat(dct['time'])
    return dct

json.loads(json_str, object_hook=custom_decoder)
```

### collections 详解

```python
from collections import (
    Counter, defaultdict, deque, namedtuple,
    OrderedDict, ChainMap
)

# Counter：计数器
c = Counter("abracadabra")  # Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})
c.most_common(2)             # [('a', 5), ('b', 2)]
c.update("aaaa")             # 增加计数
c.subtract("aa")             # 减少计数
c1 + c2                      # 合并计数
c1 - c2                      # 差集
c1 & c2                      # 交集（取较小值）
c1 | c2                      # 并集（取较大值）

# 实战：词频统计
words = text.lower().split()
word_freq = Counter(words)
top10 = word_freq.most_common(10)

# defaultdict：带默认值的字典
dd = defaultdict(list)
dd["key"].append(1)   # 不需要先检查 key 是否存在

dd = defaultdict(int)
dd["count"] += 1       # 默认值是 0

dd = defaultdict(lambda: "N/A")
dd["missing"]          # "N/A"

# 实战：分组
from collections import defaultdict
students = [("A班", "张三"), ("B班", "李四"), ("A班", "王五")]
groups = defaultdict(list)
for cls, name in students:
    groups[cls].append(name)
# {'A班': ['张三', '王五'], 'B班': ['李四']}

# deque：双端队列，两端操作 O(1)
dq = deque([1, 2, 3], maxlen=5)
dq.append(4)           # 右端添加
dq.appendleft(0)       # 左端添加
dq.pop()               # 右端弹出
dq.popleft()           # 左端弹出
dq.rotate(1)           # 右旋（正数右旋，负数左旋）
dq.extend([5, 6])      # 右端扩展
dq.extendleft([0, -1]) # 左端扩展（注意顺序反转）

# 实战：滑动窗口最大值
def max_sliding_window(nums, k):
    dq = deque()
    result = []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] < num:
            dq.pop()
        dq.append(i)
        if dq[0] == i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result

# namedtuple：命名元组
Point = namedtuple('Point', ['x', 'y'])
p = Point(11, y=22)
print(p.x, p.y)        # 11, 22
print(p[0], p[1])      # 11, 22
print(p._asdict())     # {'x': 11, 'y': 22}
p2 = p._replace(x=33)  # 创建新实例（不可变）

# OrderedDict（Python 3.7+ 普通 dict 已保序，但 OrderedDict 有额外功能）
od = OrderedDict()
od['a'] = 1
od['b'] = 2
od.move_to_end('a')         # 移到末尾
od.move_to_end('b', last=False)  # 移到开头
od.popitem(last=True)       # 弹出末尾
od.popitem(last=False)      # 弹出开头

# 实战：实现 LRU Cache
class LRUCache:
    def __init__(self, capacity):
        self.cache = OrderedDict()
        self.capacity = capacity

    def get(self, key):
        if key in self.cache:
            self.cache.move_to_end(key)
            return self.cache[key]
        return -1

    def put(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)

# ChainMap：合并多个字典的视图
defaults = {'color': 'red', 'size': 'medium'}
user_settings = {'color': 'blue'}
combined = ChainMap(user_settings, defaults)
print(combined['color'])  # 'blue'（优先 user_settings）
print(combined['size'])   # 'medium'（回退到 defaults）
```

### functools

```python
from functools import (
    partial, lru_cache, cache, reduce, wraps,
    total_ordering, singledispatch, cached_property
)

# partial：偏函数
int_base2 = partial(int, base=2)
print(int_base2('1010'))  # 10

# lru_cache：LRU 缓存
@lru_cache(maxsize=128)
def fibonacci(n):
    if n < 2: return n
    return fibonacci(n-1) + fibonacci(n-2)

fibonacci.cache_info()   # 缓存统计
fibonacci.cache_clear()  # 清除缓存

# cache（Python 3.9+）：等价于 lru_cache(maxsize=None)
@cache
def factorial(n):
    return n * factorial(n-1) if n else 1

# reduce：累积计算
product = reduce(lambda x, y: x * y, [1, 2, 3, 4, 5])  # 120

# total_ordering：自动生成比较方法
@total_ordering
class Student:
    def __init__(self, score):
        self.score = score
    def __eq__(self, other):
        return self.score == other.score
    def __lt__(self, other):
        return self.score < other.score
    # 自动生成 __le__, __gt__, __ge__

# singledispatch：单分派泛型函数
@singledispatch
def process(data):
    raise NotImplementedError(f"不支持类型: {type(data)}")

@process.register(str)
def _(data):
    return data.upper()

@process.register(list)
def _(data):
    return [x * 2 for x in data]

process("hello")     # "HELLO"
process([1, 2, 3])   # [2, 4, 6]

# cached_property（Python 3.8+）
class DataAnalyzer:
    def __init__(self, data):
        self.data = data

    @cached_property
    def statistics(self):
        """只计算一次，结果缓存在实例 __dict__ 中"""
        return {
            'mean': sum(self.data) / len(self.data),
            'max': max(self.data),
            'min': min(self.data),
        }
```

### dataclasses

```python
from dataclasses import dataclass, field, asdict, astuple, fields

@dataclass
class User:
    name: str
    age: int
    email: str = ""
    tags: list = field(default_factory=list)  # 可变默认值用 field

    def is_adult(self) -> bool:
        return self.age >= 18

user = User("张三", 25)
print(user)               # User(name='张三', age=25, email='', tags=[])
print(asdict(user))       # {'name': '张三', 'age': 25, 'email': '', 'tags': []}
print(astuple(user))      # ('张三', 25, '', [])

# 自动生成的方法：__init__, __repr__, __eq__

# 冻结（不可变）
@dataclass(frozen=True)
class Point:
    x: float
    y: float

p = Point(1.0, 2.0)
# p.x = 3.0  # FrozenInstanceError!
# frozen=True 还自动生成 __hash__，可以作为字典键

# 排序支持
@dataclass(order=True)
class Student:
    score: float
    name: str = field(compare=False)  # 不参与比较

students = [Student(90, "张三"), Student(85, "李四"), Student(95, "王五")]
sorted(students)  # 按 score 排序

# 继承
@dataclass
class Employee(User):
    department: str = ""
    salary: float = 0.0

# field 参数详解
@dataclass
class Config:
    name: str
    debug: bool = False
    items: list = field(default_factory=list)  # 可变默认值
    _internal: str = field(default="", repr=False)  # 不显示在 repr 中
    created_at: float = field(default_factory=time.time, compare=False)  # 不参与比较

# __post_init__：初始化后处理
@dataclass
class Rectangle:
    width: float
    height: float
    area: float = field(init=False)  # 不在 __init__ 参数中

    def __post_init__(self):
        self.area = self.width * self.height

r = Rectangle(3, 4)
print(r.area)  # 12
```

## Pydantic 数据校验

```python
from pydantic import BaseModel, Field, field_validator, model_validator
from typing import Optional
from datetime import datetime

# Pydantic v2（推荐）
class UserCreate(BaseModel):
    name: str = Field(min_length=2, max_length=50)
    age: int = Field(ge=0, le=150)
    email: str
    tags: list[str] = []
    created_at: datetime = Field(default_factory=datetime.now)

    @field_validator('email')
    @classmethod
    def validate_email(cls, v: str) -> str:
        if '@' not in v:
            raise ValueError('邮箱格式不正确')
        return v.lower()

    @model_validator(mode='after')
    def check_model(self) -> 'UserCreate':
        if self.age < 18 and 'admin' in self.tags:
            raise ValueError('未成年人不能是管理员')
        return self

# 使用
user = UserCreate(name="张三", age=25, email="Test@Test.com")

print(user.model_dump_json())  # 转为 JSON 字符串
```

## 面试高频问题

### Q1: Python 的模块导入机制？循环导入怎么解决？
**答**：Python 按 sys.modules 缓存 -> 内置模块 -> sys.path 路径的顺序查找模块。模块首次导入时执行代码并缓存到 sys.modules，后续导入直接从缓存获取。循环导入的解决方案：(1) 延迟导入——在函数内部导入；(2) 重构——提取公共部分到第三个模块；(3) 导入整个模块而非具体名称；(4) 使用 TYPE_CHECKING 块（仅用于类型注解）。

### Q2: `__init__.py` 的作用？
**答**：(1) 标识目录为 Python 包（Python 3.3+ 不强制但推荐保留）；(2) 包被导入时自动执行，可初始化包级别变量；(3) 通过 `__all__` 控制 `import *` 的行为；(4) 提供便捷导入，让用户可以直接 `from package import ClassA`。空的 `__init__.py` 也是有效的，只起标识包的作用。

### Q3: 虚拟环境是什么？为什么需要？
**答**：虚拟环境是隔离的 Python 运行环境，有独立的 site-packages 目录。需要的原因：(1) 不同项目需要不同版本的库；(2) 避免全局安装的版本冲突；(3) 保持系统 Python 干净；(4) 确保项目可复现（配合 requirements.txt 或 lock 文件）。常用工具：venv（自带）、poetry（推荐）、uv（最快）、conda（数据科学）。

### Q4: `dataclass` 和普通类的区别？
**答**：`@dataclass` 自动生成 `__init__`, `__repr__`, `__eq__` 等方法，减少样板代码。支持 `frozen=True`（不可变）、`order=True`（可比较）、`field()` 自定义字段行为、`__post_init__` 初始化后处理。与普通类的区别：更适合数据容器，写法更简洁。与 NamedTuple 的区别：dataclass 可变（除非 frozen）、支持默认值和继承。

### Q5: Python 类型提示的作用？运行时检查吗？
**答**：类型提示（Type Hints）仅用于**静态分析**，Python 运行时**不做类型检查**。作用：(1) IDE 代码补全和错误提示；(2) mypy/pyright 等工具做静态类型检查；(3) 提升代码可读性和可维护性；(4) Pydantic 利用类型注解做运行时校验。常用类型：Optional, Union, List, Dict, Callable, Literal, Protocol, TypeVar。

### Q6: Pydantic 和 dataclass 的区别？
**答**：核心区别是 Pydantic 做运行时校验和类型转换，dataclass 不做。Pydantic 优势：(1) 自动类型转换（`"25"` -> `25`）；(2) 数据校验（`Field(ge=0)`）；(3) JSON 序列化/反序列化；(4) 嵌套模型验证；(5) 配合 FastAPI 自动生成 API 文档。dataclass 优势：(1) 标准库，无额外依赖；(2) 更轻量；(3) 适合内部数据结构。

### Q7: poetry 和 pip 的区别？为什么推荐 poetry？
**答**：pip 只负责安装包，不管理虚拟环境和依赖解析。poetry 是完整的项目管理工具：(1) 自动管理虚拟环境；(2) 精确的依赖解析（避免版本冲突）；(3) lock 文件保证可复现；(4) 区分生产依赖和开发依赖；(5) 支持构建和发布到 PyPI；(6) 使用 pyproject.toml 标准格式。

### Q8: 如何组织大型 Python 项目的模块结构？
**答**：推荐结构：
```
project/
    pyproject.toml
    src/
        mypackage/
            __init__.py
            core/
            api/
            models/
            services/
            utils/
    tests/
    docs/
```
原则：(1) 按功能/领域分包，不按技术层次；(2) 避免循环依赖；(3) 公共接口在 `__init__.py` 中暴露；(4) 使用 `src/` 布局避免意外导入。

### Q9: collections 模块中最有用的数据结构？
**答**：(1) **Counter**——计数器，词频统计、投票计票；(2) **defaultdict**——自动初始化默认值，分组聚合；(3) **deque**——双端队列，O(1) 两端操作，实现 BFS、滑动窗口；(4) **OrderedDict**——有序字典，实现 LRU Cache（`move_to_end` + `popitem`）；(5) **namedtuple**——命名元组，轻量不可变数据容器；(6) **ChainMap**——多字典视图，配置层叠覆盖。

### Q10: functools.lru_cache 和 functools.cache 有什么区别？什么时候用？
**答**：`cache` 等价于 `lru_cache(maxsize=None)`，无限缓存。`lru_cache` 有大小限制，满时淘汰最近最少使用的条目。使用场景：(1) 纯函数（相同输入相同输出）的结果缓存；(2) 递归函数的记忆化（如斐波那契）；(3) 昂贵计算的缓存。注意事项：参数必须可哈希；缓存与函数生命周期绑定；可用 `cache_info()` 监控命中率。`cached_property` 适合实例方法的一次性计算缓存。
