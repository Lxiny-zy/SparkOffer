# Python 常用第三方库

本章覆盖 Python 后端/AI 开发必备三方库。

## 一、Web 框架

### 1. FastAPI（推荐）

**特点**：异步、自动生成文档、Pydantic 强类型、性能接近 Go。

```python
from fastapi import FastAPI, Depends, HTTPException
from pydantic import BaseModel

app = FastAPI()

class User(BaseModel):
    name: str
    age: int

@app.get("/users/{uid}")
async def get_user(uid: int):
    return {"uid": uid, "name": "Alice"}

@app.post("/users")
async def create_user(user: User):
    return user

# 依赖注入
async def get_db():
    db = Database()
    try: yield db
    finally: db.close()

@app.get("/data")
async def data(db = Depends(get_db)):
    return db.query(...)

# 运行
# uvicorn main:app --reload
```

**特性**：
- 自动生成 OpenAPI / Swagger UI（`/docs`）
- Pydantic 请求体/响应校验
- 依赖注入
- 背景任务、WebSocket、SSE

### 2. Flask

老牌轻量，适合小项目或 API。
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

@app.route("/users/<int:uid>")
def get_user(uid):
    return jsonify({"uid": uid})

@app.route("/users", methods=["POST"])
def create():
    data = request.json
    return jsonify(data), 201
```

### 3. Django

全栈重型，内置 ORM、Admin、认证。适合传统 Web、内容站。

### 4. 对比

| 框架 | 特点 | 场景 |
|------|------|------|
| FastAPI | 异步、强类型 | API、AI 服务 |
| Flask | 灵活轻量 | 原型、简单 API |
| Django | 全栈 | 传统 Web、内容站 |
| Sanic / Starlette | 异步 | 高性能 API |
| Litestar | 新一代 | 类型安全、高性能 |

## 二、HTTP 客户端

### 1. requests（同步）

```python
import requests

r = requests.get("https://api.example.com", params={"q": "hi"}, timeout=10)
r.raise_for_status()
data = r.json()

# POST
r = requests.post("https://api.example.com", json={"a": 1}, headers={"Auth": "Bearer xxx"})

# Session（复用连接）
s = requests.Session()
s.headers.update({"User-Agent": "my-app"})
s.get("...")
```

### 2. httpx（异步 + 同步）

requests 的现代替代，支持异步和 HTTP/2。

```python
import httpx

# 同步
r = httpx.get("https://api.example.com")

# 异步
async with httpx.AsyncClient() as client:
    r = await client.get("https://api.example.com")
```

FastAPI 官方推荐。

### 3. aiohttp

纯异步，性能强。
```python
import aiohttp, asyncio

async def main():
    async with aiohttp.ClientSession() as session:
        async with session.get("...") as r:
            return await r.text()

asyncio.run(main())
```

## 三、数据处理

### 1. Pydantic（数据校验）

```python
from pydantic import BaseModel, Field, EmailStr, field_validator
from typing import Optional

class User(BaseModel):
    name: str
    age: int = Field(ge=0, le=150)
    email: EmailStr
    tags: list[str] = []

    @field_validator('name')
    @classmethod
    def name_check(cls, v):
        if len(v) < 2: raise ValueError("太短")
        return v

u = User(name="Alice", age=25, email="a@b.com")
u.model_dump()         # → dict
u.model_dump_json()    # → json

# 从 JSON/dict 构造
User.model_validate(json_data)
User.model_validate_json(json_str)
```

Pydantic v2（2023+）用 Rust 重写，性能飞跃。

**应用**：
- FastAPI 请求/响应模型
- LLM 结构化输出
- 配置管理（pydantic-settings）

数据分析瑞士军刀。

```python
pd.merge(df1, df2, on='user_id', how='left')
```

## 四、数据库

### 1. SQLAlchemy（ORM）

**Core（类 SQL）**：
```python
from sqlalchemy import create_engine, text

engine = create_engine("postgresql://user:pwd@host/db")
with engine.connect() as conn:
    result = conn.execute(text("SELECT * FROM users WHERE age > :age"), {"age": 18})
    for row in result:
        print(row)
```

**ORM**：
```python
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import create_engine

class Base(DeclarativeBase): pass

class User(Base):
    __tablename__ = "users"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str]
    age: Mapped[int]

engine = create_engine("...")
Base.metadata.create_all(engine)

from sqlalchemy.orm import Session
with Session(engine) as session:
    session.add(User(name="Alice", age=25))
    session.commit()

    users = session.query(User).filter(User.age > 18).all()
```

**SQLAlchemy 2.0 + async**：
```python
from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession
engine = create_async_engine("postgresql+asyncpg://...")
async with AsyncSession(engine) as session:
    result = await session.execute(select(User).filter(User.age > 18))
```

## 五、异步与并发

### 1. asyncio

标准库，Python 3.4+。
```python
import asyncio

async def worker(name, delay):
    await asyncio.sleep(delay)
    return f"{name} done"

async def main():
    results = await asyncio.gather(
        worker("A", 1), worker("B", 2)
    )
    print(results)

asyncio.run(main())
```

### 2. uvloop

替换 asyncio 事件循环，性能提升 2-4 倍。
```python
import uvloop
uvloop.install()  # 或 asyncio.set_event_loop_policy(uvloop.EventLoopPolicy())
```

### 3. concurrent.futures

```python
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor

with ThreadPoolExecutor(max_workers=10) as pool:
    results = list(pool.map(fetch, urls))

with ProcessPoolExecutor() as pool:
    results = list(pool.map(heavy_compute, data))
```

### 4. Celery

分布式任务队列。

## 面试高频问题

**Q1：FastAPI 为什么选它？**

- **异步原生**：基于 Starlette + asyncio，高性能
- **类型驱动**：Pydantic 校验 + 自动文档（Swagger UI）
- **依赖注入**：灵活、可测
- **现代**：Python 3.8+ type hints
- 性能接近 Go / Node

适合 AI 应用、微服务、高并发 API。

**Q2：Pydantic v2 和 v1 区别？**

v2（2023）重写，用 Rust 实现核心：
- 性能提升 5-50 倍
- API 变更：`dict()` → `model_dump()`、`parse_obj()` → `model_validate()`
- `@validator` → `@field_validator` / `@model_validator`
- 类型更严格
- 新功能：Strict 模式、更多 field 类型

生产推荐 v2，v1 已维护模式。

**Q3：异步编程坑？**

- 在 async 里调阻塞函数（`time.sleep`、`requests.get`）→ 阻塞事件循环，用 `asyncio.to_thread` 切线程
- 忘记 await：协程不执行
- 混用同步和异步 ORM
- 异常未处理：`gather(..., return_exceptions=True)`
- 资源泄漏：`async with` 管理连接/会话

**Q4：requests、httpx、aiohttp 怎么选？**

- **requests**：同步、成熟，简单脚本
- **httpx**：同步+异步双支持、HTTP/2、requests 替代
- **aiohttp**：纯异步，性能略强，用于高并发爬虫

FastAPI 项目推荐 httpx。

**Q5：SQLAlchemy ORM 性能如何优化？**

- **批量**：`session.bulk_save_objects` / `bulk_insert_mappings`
- **避免 N+1**：`joinedload` / `selectinload`
- **投影**：只查需要字段
- **原生 SQL**：复杂查询直接写 SQL
- **连接池**：`pool_size`、`max_overflow`
- **异步**：SQLAlchemy 2.0 支持 asyncio

**Q6：Pandas 和 Polars 怎么选？**

- **Pandas**：生态广、学习资源多，适合小-中等数据
- **Polars**：Rust 写、比 Pandas 快 10-100 倍、支持懒执行、多核，适合大数据

趋势：Polars 快速崛起，新项目可考虑。

**Q7：日志怎么设计？**

- **结构化**（JSON）：便于 ELK 检索
- **分级**：DEBUG/INFO/WARN/ERROR
- **TraceID**：贯穿请求
- **脱敏**：不记录敏感信息
- **滚动**：按大小/时间

工具：loguru（简单）、structlog（结构化）、logging（标准）+ Filebeat + ELK。

**Q8：依赖管理工具怎么选？**

- **pip + venv**：标准但原始
- **poetry**：一站式，成熟流行
- **pdm**：PEP 标准、类似 poetry
- **uv**：最快（Rust 写），pip 替代

新项目推荐 **poetry** 或 **uv**。

**Q9：如何测试异步代码？**

```python
import pytest
import pytest_asyncio

@pytest.mark.asyncio
async def test_async():
    result = await my_async_func()
    assert result == expected
```

Mock 异步：
```python
from unittest.mock import AsyncMock
mock = AsyncMock(return_value={"data": "x"})
```

**Q10：生产 Python Web 服务部署怎么做？**

```
客户端 → Nginx → Uvicorn/Gunicorn (Worker)
                    ↓
               FastAPI / Django
                    ↓
              DB / Redis / MQ
```

- **ASGI Server**：Uvicorn、Hypercorn（FastAPI）
- **多进程**：Gunicorn + UvicornWorker（CPU 多核）
- **K8s**：HPA、健康检查、滚动更新
- **监控**：Prometheus + Grafana + Sentry
- **日志**：结构化 → ELK/Loki
- **配置**：环境变量 + pydantic-settings
