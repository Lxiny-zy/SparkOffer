# Python 面向对象编程

## 类与对象

### 基础概念

- **类（Class）**：对象的蓝图/模板，定义属性和行为
- **对象（Object）**：类的实例，拥有具体的属性值
- **属性（Attribute）**：对象的数据（变量）
- **方法（Method）**：对象的行为（函数）
- Python 中一切皆对象，包括类本身（类是 `type` 的实例）

```python
class Person:
    species = "Human"  # 类变量，所有实例共享，存在类的 __dict__ 中

    def __init__(self, name, age):  # 初始化方法（不是构造方法，__new__ 才是）
        self.name = name   # 实例变量，存在实例的 __dict__ 中
        self.age = age

    def greet(self):  # 实例方法，第一个参数 self 是实例本身
        return f"Hi, I'm {self.name}"

    @classmethod
    def from_string(cls, s):  # 类方法，第一个参数是类本身
        name, age = s.split(",")
        return cls(name, int(age))  # 用 cls 而非 Person，支持子类

    @staticmethod
    def is_adult(age):  # 静态方法，和类和实例无关
        return age >= 18

# 实例化
p = Person("张三", 25)

# 属性查找顺序：实例 __dict__ -> 类 __dict__ -> 父类 __dict__ -> ...
print(p.__dict__)      # {'name': '张三', 'age': 25}
print(Person.__dict__) # 包含 species, __init__, greet 等

# 类变量 vs 实例变量
p1 = Person("张三", 25)
p2 = Person("李四", 30)
print(p1.species)  # "Human"，从类获取
p1.species = "Alien"  # 创建了实例变量，遮蔽了类变量
print(p1.species)  # "Alien"（实例变量）
print(p2.species)  # "Human"（仍然是类变量）
print(Person.species)  # "Human"（类变量未变）
```

### 三种方法对比

```python
class MyClass:
    class_var = "shared"

    def instance_method(self):
        """实例方法：
        - 第一个参数是 self（实例）
        - 可以访问实例变量和类变量
        - 通过实例调用
        """
        return f"实例方法, self={self}, class_var={self.class_var}"

    @classmethod
    def class_method(cls):
        """类方法：
        - 第一个参数是 cls（类）
        - 只能访问类变量，不能访问实例变量
        - 常用作工厂方法（替代构造函数）
        - 通过类或实例调用
        """
        return f"类方法, cls={cls}, class_var={cls.class_var}"

    @staticmethod
    def static_method():
        """静态方法：
        - 没有 self 或 cls 参数
        - 不能访问实例或类变量
        - 本质就是放在类命名空间下的普通函数
        - 用于与类相关但不依赖实例/类状态的逻辑
        """
        return "静态方法"

# 调用方式
obj = MyClass()
obj.instance_method()      # 实例方法
MyClass.class_method()     # 类方法（通过类调用）
obj.class_method()         # 类方法（通过实例也可调用）
MyClass.static_method()    # 静态方法
obj.static_method()        # 静态方法
```

### 封装

```python
class Account:
    def __init__(self, owner, balance):
        self.owner = owner          # 公开属性
        self._internal = "内部使用"  # 约定私有（单下划线），外部不建议访问
        self.__balance = balance     # 名称改写（双下划线），变为 _Account__balance

    @property
    def balance(self):
        """getter：只读访问"""
        return self.__balance

    @balance.setter
    def balance(self, value):
        """setter：写入校验"""
        if not isinstance(value, (int, float)):
            raise TypeError("余额必须是数字")
        if value < 0:
            raise ValueError("余额不能为负")
        self.__balance = value

    @balance.deleter
    def balance(self):
        """deleter：删除控制"""
        raise AttributeError("不能删除余额")

acc = Account("张三", 1000)
print(acc.balance)         # 1000，通过 getter 访问
acc.balance = 2000         # 通过 setter 设置
# acc.balance = -100       # ValueError
# del acc.balance          # AttributeError

# 名称改写不是真正的私有，只是改了名字
print(acc._Account__balance)  # 2000，仍然可以访问

# 约定：单下划线表示"内部使用"，双下划线表示"避免子类冲突"
# Python 没有真正的访问控制，一切靠约定
```

#### @property 高级用法

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value <= 0:
            raise ValueError("半径必须大于0")
        self._radius = value

    @property
    def area(self):
        """计算属性：每次访问都重新计算"""
        return 3.14159 * self._radius ** 2

    @property
    def diameter(self):
        return self._radius * 2

    @diameter.setter
    def diameter(self, value):
        self._radius = value / 2

c = Circle(5)
print(c.area)      # 78.53975
print(c.diameter)  # 10
c.diameter = 20    # 设置直径会自动更新半径
print(c.radius)    # 10.0

# 缓存属性（避免重复计算）
class ExpensiveComputation:
    def __init__(self, data):
        self._data = data
        self._result = None

    @property
    def result(self):
        if self._result is None:
            print("开始计算...")
            self._result = sum(self._data)  # 假设很耗时
        return self._result

# Python 3.8+ 可用 functools.cached_property
from functools import cached_property

class DataProcessor:
    def __init__(self, data):
        self.data = data

    @cached_property
    def processed(self):
        """只计算一次，结果缓存在实例 __dict__ 中"""
        print("处理数据...")
        return sorted(self.data)
```

#### 多继承与 MRO

```python
# MRO（Method Resolution Order）：方法解析顺序
# 使用 C3 线性化算法，确保一致性和单调性

class A:
    def method(self):
        print("A.method")

class B(A):
    def method(self):
        print("B.method")
        super().method()

class C(A):
    def method(self):
        print("C.method")
        super().method()

class D(B, C):
    def method(self):
        print("D.method")
        super().method()

d = D()
d.method()
# 输出：D.method -> B.method -> C.method -> A.method
# MRO：D -> B -> C -> A -> object

print(D.__mro__)
# (<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>)

# super() 的本质
# super() 不是"调用父类方法"，而是"调用 MRO 中下一个类的方法"
# 这在多继承中非常重要

# 菱形继承问题
class Base:
    def __init__(self):
        print("Base.__init__")

class Left(Base):
    def __init__(self):
        print("Left.__init__")
        super().__init__()

class Right(Base):
    def __init__(self):
        print("Right.__init__")
        super().__init__()

class Child(Left, Right):
    def __init__(self):
        print("Child.__init__")
        super().__init__()

# Child() 输出：
# Child.__init__
# Left.__init__
# Right.__init__
# Base.__init__    -- 只调用一次！super() + MRO 保证了这一点

# Mixin 模式：用多继承组合功能
class JsonMixin:
    def to_json(self):
        import json
        return json.dumps(self.__dict__)

class LogMixin:
    def log(self, message):
        print(f"[{self.__class__.__name__}] {message}")

class User(JsonMixin, LogMixin):
    def __init__(self, name, age):
        self.name = name
        self.age = age

user = User("张三", 25)
```

```python
from abc import ABC, abstractmethod

class Shape(ABC):

    def area(self) -> float:

    @abstractmethod
    def perimeter(self) -> float:
        """计算周长"""

        return self.width * self.height
```

## 魔术方法（Dunder Methods）

### 对象创建与初始化

```python
class MyClass:
    def __new__(cls, *args, **kwargs):
        """
        创建实例（真正的构造方法）
        - 在 __init__ 之前调用
        - 返回实例对象
        - 很少重写，除非：单例模式、不可变类型子类化、元类
        """
        print("__new__ called")
        instance = super().__new__(cls)
        return instance

    def __init__(self, value):
        """
        初始化实例
        - 在 __new__ 之后调用
        - 不返回任何值（只能返回 None）
        """
        print("__init__ called")
        self.value = value

    def __del__(self):
        """
        析构方法，对象被垃圾回收时调用
        - 不保证何时调用
        - 不要依赖它做关键清理，用上下文管理器代替
        """
        print(f"__del__ called for {self.value}")

obj = MyClass(42)
# 输出: __new__ called / __init__ called
```

### 字符串表示

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        """用户友好的字符串，str(obj) 和 print(obj) 调用"""
        return f"({self.x}, {self.y})"

    def __repr__(self):
        """
        开发者字符串，repr(obj) 和交互式环境显示
        最佳实践：返回能重新创建对象的表达式
        """
        return f"Point({self.x!r}, {self.y!r})"

    def __format__(self, format_spec):
        """f-string 和 format() 调用"""
        if format_spec == 'polar':
            import math
            r = math.sqrt(self.x**2 + self.y**2)
            theta = math.atan2(self.y, self.x)
            return f"({r:.2f}, {math.degrees(theta):.1f}°)"
        return str(self)

p = Point(3, 4)
print(str(p))       # (3, 4)
print(repr(p))      # Point(3, 4)
print(f"{p:polar}")  # (5.00, 53.1°)
```

### 比较与哈希

```python
from functools import total_ordering

@total_ordering  # 只需实现 __eq__ 和一个比较方法，自动生成其余
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __eq__(self, other):
        if not isinstance(other, Student):
            return NotImplemented  # 返回 NotImplemented 而非 False
        return self.score == other.score

    def __lt__(self, other):
        if not isinstance(other, Student):
            return NotImplemented
        return self.score < other.score

    def __hash__(self):
        """
        实现了 __eq__ 就必须实现 __hash__（否则变为不可哈希）
        规则：a == b 则 hash(a) == hash(b)
        """
        return hash(self.score)

s1 = Student("张三", 90)
s2 = Student("李四", 85)
print(s1 > s2)   # True
print(s1 >= s2)  # True（由 @total_ordering 自动生成）
```

### 容器协议

```python
class Matrix:
    def __init__(self, rows):
        self._rows = rows

    def __len__(self):
        """len(obj)"""
        return len(self._rows)

    def __getitem__(self, index):
        """obj[index]，支持切片"""
        if isinstance(index, tuple):
            row, col = index
            return self._rows[row][col]
        return self._rows[index]

    def __setitem__(self, index, value):
        """obj[index] = value"""
        if isinstance(index, tuple):
            row, col = index
            self._rows[row][col] = value
        else:
            self._rows[index] = value

    def __contains__(self, item):
        """item in obj"""
        return any(item in row for row in self._rows)

    def __iter__(self):
        """for x in obj"""
        for row in self._rows:
            yield from row

m = Matrix([[1, 2], [3, 4]])
print(m[0, 1])    # 2
print(3 in m)     # True
print(list(m))    # [1, 2, 3, 4]
```

### 运算符重载

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        """self + other"""
        if isinstance(other, Vector):
            return Vector(self.x + other.x, self.y + other.y)
        return NotImplemented

    def __radd__(self, other):
        """other + self（当 other 不支持 __add__ 时调用）"""
        return self.__add__(other)

    def __mul__(self, scalar):
        """self * scalar"""
        if isinstance(scalar, (int, float)):
            return Vector(self.x * scalar, self.y * scalar)
        return NotImplemented

    def __rmul__(self, scalar):
        """scalar * self"""
        return self.__mul__(scalar)

    def __abs__(self):
        """abs(obj)"""
        return (self.x**2 + self.y**2) ** 0.5

    def __bool__(self):
        """bool(obj)"""
        return abs(self) > 0

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)      # Vector(4, 6)
print(v1 * 3)       # Vector(3, 6)
print(3 * v1)       # Vector(3, 6)
print(abs(v2))      # 5.0
```

```python
class CacheDecorator:
    def __init__(self, func):
        self.func = func
        self.cache = {}

    def __call__(self, *args):
        if args not in self.cache:
            self.cache[args] = self.func(*args)
        return self.cache[args]

@CacheDecorator
def fibonacci(n):

        return n
```

## 描述符协议（Descriptor Protocol）

描述符是 Python 属性访问机制的核心，`@property`、`@classmethod`、`@staticmethod` 底层都是描述符。

```python
# 描述符：实现了 __get__、__set__、__delete__ 中任一方法的类

class Validator:
    """数据描述符：同时实现 __get__ 和 __set__"""

    def __init__(self, min_value=None, max_value=None):
        self.min_value = min_value
        self.max_value = max_value

    def __set_name__(self, owner, name):
        """Python 3.6+，自动获取属性名"""
        self.name = name
        self.private_name = f'_{name}'

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self  # 通过类访问返回描述符本身
        return getattr(obj, self.private_name, None)

    def __set__(self, obj, value):
        if self.min_value is not None and value < self.min_value:
            raise ValueError(f"{self.name} 不能小于 {self.min_value}")
        if self.max_value is not None and value > self.max_value:
            raise ValueError(f"{self.name} 不能大于 {self.max_value}")
        setattr(obj, self.private_name, value)

class Product:
    price = Validator(min_value=0)          # 描述符实例作为类变量
    quantity = Validator(min_value=0, max_value=10000)

    def __init__(self, name, price, quantity):
        self.name = name
        self.price = price          # 触发 Validator.__set__
        self.quantity = quantity

p = Product("iPhone", 999, 100)
print(p.price)      # 999，触发 Validator.__get__
# p.price = -1      # ValueError!

# 属性查找优先级（关键！）：
# 1. 数据描述符（有 __get__ 和 __set__）
# 2. 实例 __dict__
# 3. 非数据描述符（只有 __get__）和其他类属性
# 这就是为什么 @property 能拦截属性赋值
```

### 用描述符实现 @property 的原理

```python
class Property:
    """模拟 @property 的实现"""

    def __init__(self, fget=None, fset=None, fdel=None, doc=None):
        self.fget = fget
        self.fset = fset
        self.fdel = fdel
        self.__doc__ = doc or (fget.__doc__ if fget else None)

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        if self.fget is None:
            raise AttributeError("不可读")
        return self.fget(obj)

    def __set__(self, obj, value):
        if self.fset is None:
            raise AttributeError("不可写")
        self.fset(obj, value)

    def setter(self, fset):
        return type(self)(self.fget, fset, self.fdel, self.__doc__)
```

## __slots__

```python
class RegularClass:

class SlottedClass:

# __slots__ 的限制
# s.z = 3  # AttributeError! 不能添加 __slots__ 之外的属性
# s.__dict__  # AttributeError! 没有 __dict__

# __slots__ 与继承
class Child(SlottedClass):
    __slots__ = ('z',)  # 子类需要声明自己的 __slots__

    def __init__(self, x, y, z):
        super().__init__(x, y)
        self.z = z

# 注意：如果子类不声明 __slots__，子类实例仍会有 __dict__
class BadChild(SlottedClass):
    pass  # 没有 __slots__，BadChild 实例会有 __dict__

# 使用场景：
# 1. 大量实例（>1000）的轻量对象，节省内存
# 2. 防止意外添加属性
# 3. 不适用于需要动态添加属性的场景
```

## 元类 Metaclass

### 理解元类

```python
# 类是对象的模板，元类是类的模板
# 类是 type 的实例：type 是默认元类
print(type(int))     # <class 'type'>
print(type(str))     # <class 'type'>
print(type(type))    # <class 'type'>  type 的元类是它自己

# 用 type 动态创建类
# type(name, bases, attrs) -> 新类
Dog = type('Dog', (object,), {
    'species': 'Canis',
    'bark': lambda self: 'Woof!',
})

d = Dog()
print(d.bark())     # Woof!
print(type(d))      # <class '__main__.Dog'>
```

### 自定义元类

```python
class SingletonMeta(type):
    """单例元类"""
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Database(metaclass=SingletonMeta):
    def __init__(self, host="localhost"):
        self.host = host

db1 = Database("server1")
db2 = Database("server2")
print(db1 is db2)     # True
print(db1.host)       # server1

# 接口检查元类
class InterfaceMeta(type):
    """确保子类实现了必要的方法"""

    def __new__(mcs, name, bases, namespace):
        cls = super().__new__(mcs, name, bases, namespace)

        # 跳过抽象基类本身
        if bases:
            required_methods = getattr(cls, '_required_methods', [])
            for method in required_methods:
                if method not in namespace:
                    raise TypeError(
                        f"类 {name} 必须实现 {method} 方法"
                    )

        return cls

class Plugin(metaclass=InterfaceMeta):
    _required_methods = ['run', 'stop']

# class BadPlugin(Plugin):
#     def run(self):
#         pass
#     # TypeError: 类 BadPlugin 必须实现 stop 方法

class GoodPlugin(Plugin):
    def run(self):
        pass
    def stop(self):
        pass

# ORM 示例（简化版 Django Model 原理）
class Field:
    def __init__(self, field_type):
        self.field_type = field_type

class ModelMeta(type):
    def __new__(mcs, name, bases, namespace):
        fields = {}
        for key, value in namespace.items():
            if isinstance(value, Field):
                fields[key] = value
        namespace['_fields'] = fields
        return super().__new__(mcs, name, bases, namespace)

class Model(metaclass=ModelMeta):
    def save(self):
        fields = ', '.join(f"{k}={getattr(self, k, None)}" for k in self._fields)
        print(f"INSERT INTO {self.__class__.__name__} ({fields})")

class User(Model):
    name = Field('VARCHAR(100)')
    age = Field('INTEGER')

    def __init__(self, name, age):
        self.name = name
        self.age = age

user = User("张三", 25)
user.save()  # INSERT INTO User (name=张三, age=25)
```

```python
# 轻量级替代元类的方案
class PluginBase:
```

## 设计模式

### 单例模式（多种实现）

```python
# 方式1：元类
class SingletonMeta(type):
    _instances = {}
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

# 方式2：装饰器
def singleton(cls):
    instances = {}
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

# 方式3：__new__
class Singleton:
    _instance = None
    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

# 方式4：模块（最简单，推荐）
# config.py
# class _Config:
#     def __init__(self):
#         self.debug = False
# config = _Config()
# 导入时：from config import config
```

### 工厂模式

```python
class Animal:
    def speak(self):
        raise NotImplementedError

class Dog(Animal):
    def speak(self):
        return "Woof!"

class Cat(Animal):
    def speak(self):
        return "Meow!"

class AnimalFactory:
    _registry = {}

    @classmethod
    def register(cls, animal_type, animal_class):
        cls._registry[animal_type] = animal_class

    @classmethod
    def create(cls, animal_type, *args, **kwargs):
        if animal_type not in cls._registry:
            raise ValueError(f"Unknown animal type: {animal_type}")
        return cls._registry[animal_type](*args, **kwargs)

AnimalFactory.register("dog", Dog)
AnimalFactory.register("cat", Cat)

animal = AnimalFactory.create("dog")
print(animal.speak())  # Woof!
```

## 最佳实践

1. **优先用组合而非继承**：继承深度不超过 3 层
2. **使用 ABC 定义接口**：明确契约，而非依赖文档
3. **实现 `__repr__` 用于调试**：返回能重建对象的字符串
4. **使用 @dataclass 减少样板代码**：简单数据类不需要手写 __init__
5. **__slots__ 用于大量轻量对象**：节省 40%-50% 内存
6. **避免过度使用元类**：`__init_subclass__` 和装饰器通常足够
7. **遵循 SOLID 原则**：单一职责、开闭原则、里氏替换等
8. **类型注解**：用 type hints 标注方法参数和返回值
9. **property 代替 getter/setter**：保持 Pythonic 风格
10. **Mixin 用于横切关注点**：日志、序列化、缓存等

## 面试高频问题

### Q1: `__new__` 和 `__init__` 的区别？
**答**：`__new__` 是静态方法（虽然不需要 @staticmethod 修饰），负责创建并返回实例对象，第一个参数是 cls；`__init__` 是实例方法，负责初始化已创建的实例，第一个参数是 self，不返回任何值。调用顺序：先 `__new__` 创建实例，再 `__init__` 初始化。`__new__` 的典型重写场景：单例模式、不可变类型子类化。

### Q2: classmethod, staticmethod, 实例方法的区别？
**答**：实例方法第一个参数是 self（实例），可访问实例和类属性；类方法用 @classmethod 装饰，第一个参数是 cls（类），常用作工厂方法；静态方法用 @staticmethod 装饰，没有 self 或 cls，本质是放在类命名空间下的普通函数。继承时，classmethod 的 cls 会自动指向子类，这是它比 staticmethod 更灵活的地方。

### Q3: Python 的多继承和 MRO 是怎么工作的？
**答**：Python 使用 C3 线性化算法计算 MRO（方法解析顺序）。C3 算法保证：(1) 子类在父类之前；(2) 多个父类按声明顺序；(3) 保持单调性（不会出现矛盾的顺序）。`super()` 不是调用父类方法，而是调用 MRO 中下一个类的方法。可以通过 `cls.__mro__` 或 `cls.mro()` 查看。菱形继承中，共同基类的方法只会调用一次。

### Q4: 什么是鸭子类型？和接口有什么区别？
**答**：鸭子类型是动态类型语言的特征——"如果走起来像鸭子，叫起来像鸭子，那就是鸭子"。Python 不关心对象的类型，只关心它有没有需要的方法/属性。与 Java 接口的区别：(1) 接口是显式的，鸭子类型是隐式的；(2) 鸭子类型不需要继承或实现声明；(3) 缺点是运行时才能发现错误。Python 3.8+ 的 Protocol 类提供了结构化子类型检查。

### Q5: 如何实现单例模式？各方式的优缺点？
**答**：(1) 元类方式——线程安全（加锁后），最通用；(2) 装饰器方式——简洁但丢失类信息；(3) `__new__` 方式——简单但每次调用 `__init__` 会重复初始化；(4) 模块方式——最简单最 Pythonic，Python 模块天然是单例。推荐模块方式用于简单场景，元类方式用于需要继承的场景。

### Q6: 描述符协议是什么？@property 的原理？
**答**：描述符是实现了 `__get__`、`__set__`、`__delete__` 中任一方法的类。数据描述符（有 `__set__`）优先于实例 `__dict__`，非数据描述符（只有 `__get__`）低于实例 `__dict__`。`@property` 底层就是一个数据描述符，它拦截属性访问并调用 getter/setter 函数。属性查找优先级：数据描述符 > 实例 __dict__ > 非数据描述符/类属性。

### Q7: __slots__ 是什么？什么时候使用？
**答**：`__slots__` 是类变量，指定实例可以拥有的属性名。使用后实例不再有 `__dict__`，改为用更紧凑的方式存储属性，节省约 40-50% 内存。适用于大量实例的轻量对象。限制：不能动态添加属性，不支持 weakref（除非加入 `'__weakref__'`），继承需要注意子类也要声明自己的 `__slots__`。

### Q8: 元类的应用场景？__init_subclass__ 可以替代元类吗？
**答**：元类用于控制类的创建过程，应用场景：ORM（如 Django Model 自动创建数据库映射）、API 注册、接口约束检查、单例。`__init_subclass__`（Python 3.6+）可以替代许多简单的元类用法，如插件注册、子类验证等。一般原则：优先用 `__init_subclass__` 或类装饰器，只有在需要控制类创建过程（如修改类属性、拦截 `__new__`）时才用元类。

### Q9: Python 中的属性查找顺序是什么？
**答**：实例属性查找顺序：(1) 数据描述符（类及其 MRO 中有 `__get__` + `__set__` 的描述符）；(2) 实例 `__dict__`；(3) 非数据描述符（只有 `__get__`）和类变量；(4) 如果都没找到，调用 `__getattr__`（如果定义了的话）。注意 `__getattribute__` 在每次属性访问时都会调用（除非直接用 `object.__getattribute__`），而 `__getattr__` 只在属性未找到时调用。

### Q10: 如何让自定义对象支持 with 语句？
**答**：实现 `__enter__` 和 `__exit__` 方法。`__enter__` 在进入 with 块时调用，返回值绑定到 as 变量；`__exit__` 在离开 with 块时调用，接收异常信息（exc_type, exc_val, exc_tb），返回 True 表示抑制异常，返回 False 表示传播异常。也可以用 `@contextmanager` 装饰器简化实现。详见 [06_异常处理与上下文管理](./06_异常处理与上下文管理.md)。
