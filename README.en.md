## What is SparkOffer

SparkOffer is an **AI-powered interview training system** for tech-job seekers.

The problem it solves is concrete: most interview tools are stateless — random questions, generic feedback, and the next session starts from scratch. SparkOffer turns every session into a **cumulative skill-modeling process**: the AI continuously tracks your weak spots, mastery levels, thinking patterns, and communication style. The next round of questions automatically targets your weaknesses, and reviews are scheduled along the forgetting curve.

The more you train, the better the AI knows you — and the more precisely it can spark your next Offer.

## Core Highlights

### 1. Personalized Question Engine (3-layer fusion)

Instead of pulling from a fixed bank, every question is generated by fusing three layers of context:

```
┌─ Layer 3 · Long-term Profile ────────────────┐
│  Cross-domain strengths · Thinking patterns  │
│  · Communication style                       │
├─ Layer 2 · Topic Mastery ────────────────────┤
│  Mastery 0-100 · Historical weak spots       │
│  · Training insights                         │
├─ Layer 1 · Session Context ──────────────────┤
│  Resume · JD · Knowledge RAG                 │
│  · Last-20-question deduplication            │
└──────────────────────────────────────────────┘
              ↓ Injected into LangGraph
   AI interviewer generates 10 personalized questions
```

Mastery 0-30 → concept comparison; 30-60 → scenario application; 60-100 → system design and trade-offs. The first three questions precisely hit historical weak spots, then expand to new topics.

### 2. Train → Evaluate → Profile-Update Loop

Every training session is a quantifiable iteration of capability:

```
Answer → per-question scoring + weakness extraction
       → weighted mastery algorithm (confidence = difficulty/5 × score/10)
       → LLM profile update (Mem0-style ADD / UPDATE / IMPROVE)
       → vector memory ingestion (semantic recall of insights)
       → SM-2 spaced repetition scheduling
       → next question round becomes more precise
```

Mastery scoring uses a **deterministic algorithm** (no LLM subjectivity). Profile updates use **LLM-driven intelligent merging** to keep the profile compact and avoid duplication.

### 3. Multiple Training Modes

| Mode | Description |
| --- | --- |
| **Weakness Sniper** | Pick a domain, get 10 dynamically generated targeted questions with adaptive difficulty |
| **Mock Interview Arena** | LangGraph state machine: intro → tech Qs → project deep-dive → Q&A |
| **JD Boot Camp** | Extract JD requirements, fuse with resume + knowledge to generate role-fit questions |
| **Knowledge Gym** | Knowledge base split into flip cards with three depth tiers, scheduled by SM-2 |
| **Algorithm Arena** | Problem favorites, mistake replay, solution-coaching companion |
| **Q&A Arena** | Free-form deep-dives on any topic; good answers deposit back into your knowledge base |

### 4. Two-Layer Knowledge Augmentation (RAG)

- **Domain knowledge base** — LlamaIndex over your own Markdown docs, used as factual grounding for question generation and evaluation
- **Historical training memory** — insights from past sessions (weak spots, error patterns, suggestions) are embedded and semantically recalled in future rounds

### 5. Observable Growth

- Per-question scores + improvement suggestions
- Mastery radar and trend charts
- Cross-domain strength/weakness comparison
- Long-term profile (thinking patterns, communication style, recurring issues)
- Heatmap of mistakes and high-frequency questions

## Quick Start

### 1. Configure environment

```bash
cp .env.example .env
```

**Minimum required**: LLM + Embedding (one of two embedding backends).

```env
# LLM (any OpenAI-compatible endpoint)
API_BASE=https://your-llm-api-base/v1
API_KEY=sk-your-api-key
MODEL=your-model-name

# Embedding
EMBEDDING_BACKEND=api          # api | local
EMBEDDING_API_BASE=https://your-embedding-api-base/v1
EMBEDDING_API_KEY=sk-your-embedding-key
EMBEDDING_API_MODEL=BAAI/bge-m3
```

**Auth defaults** (works out of the box for local use):

```env
JWT_SECRET=change-me-in-production
DEFAULT_EMAIL=admin@sparkoffer.local
DEFAULT_PASSWORD=admin123
ALLOW_REGISTRATION=false
```

### 2. Docker (recommended)

```bash
docker compose up --build
```

Open `http://localhost`.

### 3. Manual setup

Backend:
```bash
pip install -r requirements.txt
# For local embedding: pip install -r requirements.local-embedding.txt
uvicorn backend.main:app --reload --port 8000
```

Frontend:
```bash
cd frontend
npm install
npm run dev    # http://localhost:5173
```
